# Image-Based-Breed-Recognition-for-Cattle-Buffalo-and-Sheep-in-India
A deep learning-based image recognition system for identifying Indian cattle, sheep and buffalo breeds using Swin Transformer architecture with CBAM attention mechanism. Developed as a second year project at Sri Ramakrishna Engineering College, Coimbatore.
